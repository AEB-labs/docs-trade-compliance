In the following pages, we demonstrate typical scenarios of how the Compliance Screening API may be called. The scenarios represent standard use cases which involve partner systems (e.g. ERP) that trigger the API calls and receive the respective response.

API calls to TCMs Compliance Screening API require log in credentials. We have prepared a test system, which you can use for testing purposes for free. You can find more information on the required credentials under [The First Address Screening](https://trade-compliance.docs.developers.aeb.com/v4.1/update/docs/the-first-screening-of-an-address#/) .
